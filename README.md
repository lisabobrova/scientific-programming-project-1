# Numerical Optimization in Python

This project explores numerical methods for optimization and root finding, implemented in Python as part of scientific programming coursework.

The notebook covers several numerical approaches, including the bisection method, brute-force search, gradient descent with different step-size strategies, and numerical differentiation. The methods are tested computationally and their convergence behaviour and computational cost are examined.

The project also includes an application of gradient-based optimization to an epidemic model, where the method is used to estimate the maximum daily number of new infections under a simplified model.

## Context

This project was completed as part of university coursework in scientific programming.
